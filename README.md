

# 코멘트 노드 추가와와 그룹 기능 수정 버전. 







# ![](https://raw.githubusercontent.com/Wouterdek/NodeNetwork/gh-pages/img/logo128.png) NodeNetwork [![https://www.nuget.org/packages/NodeNetwork/](https://img.shields.io/nuget/v/NodeNetwork.svg?style=flat)](https://www.nuget.org/packages/NodeNetwork/)

#### NodeNetwork는 노드 에디터 컴포넌트를 제공하는 .NET C# WPF 라이브러리입니다.

다음은 계산기 예제 애플리케이션의 데모입니다:

![](https://raw.githubusercontent.com/Wouterdek/NodeNetwork/gh-pages/img/demo1.gif)

이 라이브러리를 활용한 더 현실적인 사용 사례는 셰이더 에디터입니다.  
다음은 NodeNetwork를 사용하여 만든 셰이더 에디터 예제의 데모입니다:

![](https://raw.githubusercontent.com/Wouterdek/NodeNetwork/gh-pages/img/demo2.gif "")

이 예제 애플리케이션은 [여기](https://github.com/Wouterdek/NodeNetwork/releases)에서 다운로드할 수 있으며, 관련 소스 코드는 리포지토리에 포함되어 있습니다.
라이브러리의 바이너리 릴리스는 NuGet에서 사용할 수 있습니다.

## 주요 기능
 - .NET Framework 4.7.2 및 .NET Core 3.1 이상 버전을 위해 구축됨
 - 개방적이고 허용적인 오픈소스 라이선스
 - 최신 반응형(Reactive) MVVM 코드로 구축된 강력한 대화형 컨트롤
 - 매끄러운 패닝(Panning) 및 줌(Zoom) 제어
 - 자동 레이아웃 시스템
 - **코멘트 노드(Comment Node) 및 그룹(Group) 기능 지원**
 - 높은 자유도의 커스터마이징과 기본적으로 사용하기 쉬운 구조
 - 광범위한 네트워크 및 연결 유효성 검사 지원
 - 단위 테스트 백업 지원
 - ...
